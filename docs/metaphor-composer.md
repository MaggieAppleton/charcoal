# Metaphor composer

The composer switches between Illustration and Metaphor. Illustration keeps its existing prompt, references, settings and submission state. Metaphor retains a separate brief draft and opens saved sources or options in the same composer. An option shows its scene, meaning and caveat, with feedback and the existing prompt-block action.

Canvas sources are compact document markers. Options show a title and scene excerpt at a fixed size. Selection, drag hit testing, placement and wires share the same world-space bounds. The source links to each option by its existing brief ID. Saved coordinates and prompt links carry forward.

Exploration starts with three options. Use **+** beside **View options** to generate one more for the same brief. The request includes the kept and dismissed ideas. Use the trash button in an option’s composer or Delete on the canvas to dismiss it. The source stays available after the last option is deleted. Canvas Undo restores the option with its position, refinement history and prompt link. A prompt block stays on the canvas independently.

A pending request keeps its original brief, count and exclusions. Recover it using the saved result on its originating board. Project exports carry the request and dismissed ideas. On another board, a missing result leaves the brief available for an explicit new request.

Submission acknowledges immediately and retains the brief. Options land beside their source in free space, with a composer action to locate the group. Background results update their own cards and status without taking focus or moving the camera.

The brief can also import a public post. Readable text joins the editable draft, and the page title and final URL travel with the source and options. The server checks every redirect and the resolved address before connecting. Import supports ordinary HTTP(S) pages and plain text up to 1 MiB, with up to 32,000 characters copied into the brief. Pages that require sign-in or client rendering may need pasted text.
